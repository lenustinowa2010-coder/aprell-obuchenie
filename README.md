# APRELL — сайт обучения менеджера

Статический сайт с админкой. Контент — markdown-файлы в папке `content`.
Редактируется через `/admin`, вход по GitHub-аккаунту.

## Что внутри

```
index.html              сайт обучения
assets/style.css        оформление
assets/app.js           поиск, навигация, панель «Сейчас»
content/*.md            разделы обучения — это и есть контент
content/index.json      собирается автоматически при деплое
admin/index.html        админка (Decap CMS)
admin/config.yml        настройки админки — правится один раз
scripts/build-index.js  сборка оглавления
netlify.toml            команда сборки и заголовки

katalog/                каталог моделей — отдельное приложение
  index.html            собранная страница (её пересобирают скрипты)
  data.json             база: модели, аксессуары, материалы, вопросы
  media/                свои фото и видео (кладёте локально)
  *.py                  скрипты заливки медиа и ссылок Collonil
```

Каталог живёт своей жизнью: его правят локальными скриптами на Mac, а сюда
попадает готовый результат. Админка Decap его не трогает.

## Установка — один раз, около часа

### 1. Репозиторий

Создайте на GitHub приватный репозиторий, например `aprell-obuchenie`,
и загрузите в него всё содержимое этой папки.

### 2. Сайт на Netlify

Netlify → **Add new site** → **Import an existing project** → GitHub →
выберите репозиторий. Команду сборки и папку публикации Netlify возьмёт
из `netlify.toml`, менять ничего не нужно.

После деплоя запишите адрес вида `https://ваш-сайт.netlify.app`.

### 3. Приложение для входа

GitHub → **Settings** → **Developer settings** → **OAuth Apps** →
**New OAuth App**.

- **Homepage URL** — адрес сайта из шага 2
- **Authorization callback URL** — `https://api.netlify.com/auth/done`

Сохраните. Скопируйте **Client ID**, нажмите **Generate a new client secret**
и скопируйте секрет — он показывается один раз.

### 4. Связать Netlify с GitHub

Netlify → ваш сайт → **Site configuration** → **Access & security** →
**OAuth** → **Install provider** → GitHub → вставьте Client ID и Client Secret.

### 5. Указать репозиторий в админке

В файле `admin/config.yml` замените строку:

```yaml
repo: ВАШ-ЛОГИН/aprell-obuchenie
```

на своё. Сохраните — Netlify пересоберёт сайт сам.

### 6. Проверка

Откройте `https://ваш-сайт.netlify.app/admin`, нажмите **Login with GitHub**.
Должны появиться пять разделов.

## Как редактировать

1. Открыть `/admin`, войти через GitHub.
2. Выбрать раздел, править текст.
3. **Publish** — изменения уходят в репозиторий, сайт пересобирается за минуту.

**Ссылка на каталог в меню:** раздел «Меню» → «Ссылки на другие разделы».

**Новый раздел:** «Разделы обучения» → **New Раздел**. Заполните название,
подзаголовок и порядок — раздел сам появится в меню.

**Убрать раздел:** удалить запись в админке.

Порядок в меню задаётся полем «Порядок»: 1 — первый.

## Что важно знать

**Адрес сайта открыт всем, у кого есть ссылка.** Поисковики его не проиндексируют
(`robots.txt` и заголовок `X-Robots-Tag`), но парольной защиты нет — на бесплатном
тарифе Netlify её не существует. Если нужен вход по паролю: либо платный тариф
Netlify, либо Cloudflare Access поверх сайта на бесплатном тарифе.

**Внутри есть закупочные цены, скрипты и телефон для возвратов.** Ссылку стоит
давать только менеджерам.

**Правки идут через Git.** Каждое изменение — это коммит, история сохраняется,
любую версию можно вернуть.

**Разметка — markdown.** В админке есть визуальный редактор, знать разметку
не обязательно, но таблицы удобнее править в режиме «Markdown».

## Каталог моделей

Лежит в папке `katalog/`, открывается по адресу `адрес-сайта/katalog/`.
В меню обучения он стоит первым пунктом, с переходами сразу в нужную вкладку.

**Поиск на сайте обучения ищет и по каталогу.** При загрузке страницы читается
`katalog/data.json`, и модели, аксессуары, материалы и частые вопросы попадают
в общий поиск. Находка из каталога открывает нужную вкладку каталога.
Отдельно ничего настраивать не нужно — работает само, пока файл лежит на месте.

### Как обновлять

Всё как раньше, на Mac:

1. Сложить фото в `katalog/media_src/`, запустить `python3 prepare_media.py`.
2. Скрипт сожмёт фото, разложит в `katalog/media/`, обновит `data.json`
   и пересоберёт `katalog/index.html`.
3. Залить на GitHub изменившиеся файлы.

Пути в скриптах относительные, поэтому переезд в подпапку ничего не сломал —
главное, чтобы скрипты, `data.json` и `index.html` лежали рядом, как сейчас.

### Про фото

Через веб-интерфейс GitHub заливать сотни файлов неудобно. Для каталога
поставьте **GitHub Desktop**: положили файлы в папку — нажали Commit — Push.
Обучение при этом можно продолжать править через админку, одно другому
не мешает.

Скрипт сжимает фото до 1400 px по длинной стороне — этого хватает для экрана
и не раздувает репозиторий. Видео тяжелее: если их станет много, лучше
держать их на видеохостинге и хранить в базе ссылку.
